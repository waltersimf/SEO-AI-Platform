## ⚡ Швидкий старт

### 1️⃣ Встановлення

```bash
# 1. Перейди в папку проекту
cd forgeline

# 2. Встанови dependencies
pnpm install

# 3. Створи .env файл
cp .env.example .env

# 4. Запусти Docker (PostgreSQL + Redis)
docker-compose up -d

# Перевір що працює:
docker ps
# Має бути: forgeline-postgres та forgeline-redis
```

### 2️⃣ База даних

```bash
# 1. Generate Prisma Client
cd packages/db
pnpm prisma generate

# 2. Запусти migration
pnpm prisma migrate dev --name init

# 3. (Опціонально) Відкрий Prisma Studio
pnpm prisma studio
# Відкриється http://localhost:5555
```

### 3️⃣ Запуск проекту

```bash
# Поверни в root
cd ../..

# Запусти ВСЕ разом (recommended)
pnpm dev

# Або окремо:
pnpm dev:web    # Frontend на :3000
pnpm dev:api    # Backend на :4000
```

**Чекай поки всі сервіси стартують (~20-30 сек)**

Коли побачиш:
```
web:1  ✓ Ready in 3.2s
api:1  Nest application successfully started
```

Готово! 🎉

## 🐛 Troubleshooting

### Problem: "Cannot connect to database"
```bash
# Check Docker
docker ps

# Restart containers
docker-compose down
docker-compose up -d

# Wait 10 seconds
sleep 10

# Try again
pnpm dev
```

### Problem: "Port 3000 already in use"
```bash
# Mac/Linux:
lsof -ti:3000 | xargs kill -9
lsof -ti:4000 | xargs kill -9

# Windows:
netstat -ano | findstr :3000
taskkill /PID <PID> /F
```

### Problem: "Prisma Client not found"
```bash
cd packages/db
pnpm prisma generate
cd ../..
pnpm dev
```

### Problem: "Cannot find module '@/components/ui/...'"
```bash
# Re-install dependencies
pnpm install

# Make sure you're in root directory
pwd  # Should show .../forgeline
```
